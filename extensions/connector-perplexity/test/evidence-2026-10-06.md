## Bugs found & fixed during testing (all in-repo, none upstream)

1. `nats@2.29.3` exposes `credsAuthenticator`, not `credsFile` (v3 API);
   creds file is parsed to a Buffer and passed to `credsAuthenticator`.
2. DM durable name is derivable from the creds JWT's **pub.allow**
   `$JS.API.CONSUMER.INFO.DM_<space>.<durable>` entry (not sub.allow).
3. `inboxPrefix` must be `_INBOX_<nkey>` to match the minted JWT's core-sub
   allow-list, else JetStream calls fail with Permissions Violation.
4. Agents receive DMs **only** via the bound JetStream durable — a core
   subscription to the DM filter is not granted (by design); the tester's
   reply listener binds its durable too.
5. Self-ingest: the connector's channel receive filter matches its own
   published replies → added a self-sender drop in `ingest()`.
6. Test hygiene: e2e now kills stale connector PIDs from prior runs and always
   stops its child in a `finally` (two connectors on one durable split
   deliveries and caused one false FAIL round).
